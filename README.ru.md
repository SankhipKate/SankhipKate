# QA Engineer

[English version](README.md)

Я QA Engineer с 3 годами опыта в финтех- и AI-продуктах.

Сейчас я работаю единственным QA в команде банка Salmon над внутренним проектом для онбординга retail-агентов. Это многошаговый процесс поиска, найма и обучения агентов с десятками ветвлений.

Я выстраиваю QA-процесс с нуля: веду документацию, описываю бизнес-логику и пользовательские flow, создаю матрицы покрытия требований, пишу и поддерживаю тестовую документацию, оформляю баг-репорты с trace ID, evidence и выдержками из логов.

Также у меня есть опыт тестирования Telegram-based AI-приложения Practim — сервиса психологической самопомощи. Я проверяла промпты, диалоги нейросети, edge cases, web- и mobile-версии продукта.
